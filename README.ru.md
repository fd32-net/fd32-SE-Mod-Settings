# Mod Settings

**Центр настроек для модов Space Engineers.** Мод описывает свои настройки несколькими строками на C#, а Mod Settings
добавляет кнопку-шестерёнку рядом с **«Настройками»** в меню Esc, показывает список подключённых модов и рисует для каждого
окно настроек в ванильном стиле.

[English version](README.md)

> **Статус:** в разработке (V0.8.6). Описанное ниже API клиента проверено в игре. Страница в Workshop ещё не опубликована.

- Без чат-команд и конфиг-файлов, которые нужно объяснять игрокам: всё делается в привычном окне игры.
- Как в ванили: галочки, ползунки, поля ввода, выпадающие списки и назначение клавиш выглядят и работают так же,
  как в «Параметрах» и «Управлении» самой игры.
- Подключение — копирование одного файла. Никаких DLL, только зависимость в Workshop.
- **Центр только рисует окно.** Значения хранит мод, он же их проверяет и сам решает, что доступно и что видно.

## Быстрый старт

**1. Скопируйте клиентский файл** [`Client/ModSettings.cs`](Client/ModSettings.cs) в свой мод **без изменений**:

```
<ВашМод>\Data\Scripts\<ВашМод>\ModSettings.cs
```

Каждый мод компилируется отдельно, поэтому одинаковые имена классов в разных модах не конфликтуют.

**2. Укажите Mod Settings обязательной зависимостью** своего мода в Steam Workshop, чтобы игра скачивала центр сама.
Для локальной проверки положите этот репозиторий в `%AppData%\SpaceEngineers\Mods\Mod Settings` и добавьте в мир оба мода.

**3. Опишите настройки** в сессионном компоненте:

```csharp
using ModSettings;
using Sandbox.ModAPI;
using VRage.Game.Components;
using VRage.Input;

[MySessionComponentDescriptor(MyUpdateOrder.AfterSimulation)]
public class MyModSettings : MySessionComponentBase
{
    public static SettingsMenu Menu;
    public static NumberSetting Speed;
    public static ToggleSetting ShowHints;
    public static HotkeySetting LinkKey;

    public override void LoadData()
    {
        // id — постоянный ключ мода (не менять); имя и версия видны в меню
        Menu = new SettingsMenu("mymod", "My Mod", "1.0");
        Menu.Info("# My Mod\nЧто делает мод и как им пользоваться.");

        Speed     = Menu.Number("speed", "Скорость круиза", 20).Range(0, 100).Step(5).Unit("м/с");
        ShowHints = Menu.Toggle("hints", "Показывать подсказки", true);
        LinkKey   = Menu.Hotkey("link", "Связать", MyKeys.R);

        Menu.LoadFromLocalStorage();                       // загрузить сохранённое (необязательно)
        Menu.Applied += () => Menu.SaveToLocalStorage();   // сохранить после «ОК»
        Menu.Register();                                   // отдать меню центру
    }

    public override void UpdateAfterSimulation()
    {
        if (LinkKey.IsNewPressed())
            MyAPIGateway.Utilities.ShowNotification("Связь! Скорость = " + Speed.Value);
    }

    protected override void UnloadData()
    {
        Menu.Dispose();
    }
}
```

**4. В игре:** нажмите **Esc**, затем **шестерёнку** справа от **«Настроек»** и выберите **My Mod**.
Измените что-нибудь и нажмите **«ОК»**: новые значения окажутся в `Speed.Value`, `ShowHints.Value` и `LinkKey`.

Обычному моду больше ничего не нужно. Дальше подробно разобраны все возможности.

## Как это устроено

```
 ваш мод                                        Mod Settings (центр)
┌──────────────────────────┐   SendModMessage   ┌────────────────────────────┐
│ ModSettings.cs (клиент)  │ ─────────────────► │ шестерёнка в меню Esc      │
│  описание меню,          │                    │ список модов               │
│  значения, события       │ ◄───────────────── │ окно настроек              │
└──────────────────────────┘ правки, ОК, кнопки └────────────────────────────┘
```

- **Центр** — отдельный мод в Workshop. Он рисует шестерёнку, список модов и окно, но **ничего не хранит и не проверяет**.
- **Клиентский файл** — это всё API: описание меню, текущие значения, события и проверка клавиш.
  Ваш код работает только с ним, протокол ему не виден.
- Настройки **личные**: они хранятся на стороне клиента, и у каждого игрока свои значения.

## Окно настроек

```
┌───────────────────────────── My Mod ───────────────────────────────[×]┐
│ Основные       │ Скорость круиза                 │ # My Mod           │
│ HUD            │ ═════●═══════════════  [ 20 ]   │ Что делает мод     │
│ Клавиши        │ Показывать подсказки       [✓]  │ и как им           │
│                │ ▼ Дополнительно                 │ пользоваться.      │
│                │   Единицы                       │                    │
│                │   [ м/с                     ▼ ] │                    │
│                │                                 │                    │
│ [ По умолчанию ]                            [ Отмена ]  [   ОК   ]    │
└───────────────────────────────────────────────────────────────────────┘
   закладки         настройки выбранной закладки        текст мода
```

- **Слева** — закладки. Всё, что добавлено прямо в меню, попадает на первую закладку, **«Основные настройки»**.
- **Посередине** — настройки выбранной закладки. Колонка прокручивается колесом мыши и полосой прокрутки.
- **Справа** — произвольный текст мода. Если мод его не задал, правой колонки нет.
- **ОК / Отмена / По умолчанию** работают как в ванильных «Параметрах»:
  - до **«ОК»** в `.Value` мода ничего не попадает; **«Отмена»**, **Esc** и **×** отменяют изменения;
  - **«ОК»** недоступна, пока ничего не изменено. **Enter** никогда не нажимает «ОК», он только принимает ввод в поле;
  - **«По умолчанию»** возвращает значения по умолчанию **во всём моде** (на всех закладках). Чтобы они применились, тоже нужно нажать «ОК».
- Кнопки и надписи самого центра показываются по-русски, если в игре выбран русский язык, иначе по-английски.

## Описание меню

Элементы появляются в окне в том порядке, в каком вы их добавили. У `SettingsMenu`, `SettingsTab` и `SettingsGroup`
одинаковые методы добавления (`Toggle`, `Number`, `Choice`, `Text`, `Hotkey`, `Label`, `Separator`, `Button`).

```
SettingsMenu            строка в меню шестерёнки + окно с заголовком = имя мода
 ├─ элементы            → закладка «Основные настройки»
 ├─ Group               → заголовок раздела на «Основных настройках»
 └─ Tab                 → закладка в списке слева
     ├─ элементы
     └─ Group           → заголовок раздела; .Collapsible() — сворачивается
         └─ элементы
```

### SettingsMenu

```csharp
Menu = new SettingsMenu("mymod", "My Mod", "1.0");
```

| Член | Что делает |
|---|---|
| `new SettingsMenu(id, name, version)` | `id` — постоянный ключ мода, его нельзя менять между версиями. `name` и `version` видны в меню шестерёнки, `name` — ещё и заголовок окна. |
| `Tab(title)` | Добавляет закладку. |
| `Group(title)` | Добавляет группу на закладку «Основные настройки». |
| `Info(text)` / `Info(Func<string>)` | Текст правой колонки, см. [Правая колонка](#правая-колонка-info). |
| `CustomWindow(Action)` | Открывает своё окно вместо стандартного, см. [Своё окно](#своё-окно). |
| `Register()` | Отдаёт меню центру. Вызывается один раз, после описания всех элементов, обычно в конце `LoadData`. |
| `Dispose()` | Снимает меню. Вызывается в `UnloadData`. |
| `IsConnected` | `true`, когда центр принял меню. |
| `Opened`, `Editing`, `Applying`, `Applied`, `Closed` | События окна, см. [События](#события-от-открытия-окна-до-ок). |
| `ShowMessage`, `ShowConfirm` | Сообщения игроку, см. [Сообщения и вопросы](#сообщения-и-вопросы-игроку). |
| `LoadFromLocalStorage()`, `SaveToLocalStorage()` | Необязательный помощник сохранения, см. [Сохранение значений](#сохранение-значений). |

Моды в меню шестерёнки идут по алфавиту имён.

### Закладки и группы

```csharp
var hud   = Menu.Tab("HUD");
var hints = hud.Group("Подсказки");                       // заголовок раздела
var adv   = hud.Group("Дополнительно").Collapsible(true); // сворачивается щелчком; true — сразу свёрнута
adv.Toggle("debug", "Отладочный слой", false);
```

- Если мод не добавил ни одной закладки, в окне одна закладка — **«Основные настройки»**.
- Если есть и элементы прямо в меню, **и** закладки, то «Основные настройки» идут первыми, за ними — ваши закладки.
- `Collapsible(startCollapsed = false)` — группа сворачивается и разворачивается щелчком по заголовку.
- Группы одноуровневые: их создают из меню или закладки, но не из другой группы.

### Правая колонка (Info)

```csharp
Menu.Info("# My Mod\nСтрока один.\nСтрока два.");                 // общий текст для всех закладок
hud.Info("# HUD\nЭти настройки меняют подсказки на экране.");      // только для этой закладки
Menu.Info(() => "# Состояние\nПоездов в пути: " + TrainCount);     // живой текст
```

- Строка, начинающаяся с `# `, показывается как заголовок. Длинные строки переносятся.
- `Func<string>` вызывается заново примерно два раза в секунду — подходит для живого состояния мода.
- Если у закладки есть свой `Info`, на ней он показывается вместо `Info` меню.
- Если текста нет совсем, правой колонки нет, а средняя становится шире.

## Виды настроек

Каждый метод возвращает **объект настройки**. Сохраните его в поле и читайте `.Value` там, где нужно.
Тонкая подстройка делается цепочкой: `.Range(0, 100).Step(5).Unit("м/с")`.

`key` — постоянный ключ настройки, по нему работают сохранение и протокол. Он должен быть **уникальным в пределах меню**.

| Метод | Тип `.Value` | Вид в окне |
|---|---|---|
| `Toggle(key, label, default)` | `bool` | ванильная галочка |
| `Number(key, label, default)` | `float` (+ `IntValue`) | ползунок, поле ввода и кнопки −/+ в любой комбинации |
| `Choice(key, label, defaultKey)` | `string` (ключ варианта) | ванильный выпадающий список |
| `Text(key, label, default = "")` | `string` | ванильное поле ввода |
| `Hotkey(key, label, MyKeys, MyKeyboardModifiers = None)` | `HotkeyValue` | строка как в ванильном «Управлении» |

### Toggle — галочка

```csharp
ShowHints = Menu.Toggle("hints", "Показывать подсказки", true);
if (ShowHints.Value) { ... }
```

### Number — число

```csharp
Speed = Menu.Number("speed", "Скорость круиза", 20)
            .Range(0, 120)          // значение всегда в диапазоне; без диапазона нет ползунка
            .Step(5)                // ползунок ходит шагами, −/+ прибавляют шаг, введённое округляется к шагу
            .Decimals(0)            // знаков после запятой (по умолчанию — по шагу)
            .Unit("м/с")            // единица рядом со значением
            .Slider().Field().Buttons();   // какие элементы показать

float s = Speed.Value;
int   i = Speed.IntValue;           // округлённое до целого
```

| Вызов | Действие |
|---|---|
| `Range(min, max)` | Значение зажимается в диапазон. Без диапазона ползунка нет. |
| `Step(step)` | Действует везде: ползунок, −/+ и ввод в поле (округление отсчитывается от `min`). |
| `Decimals(n)` | От 0 до 6 знаков. По умолчанию зависит от шага (шаг 0.1 — 1 знак). |
| `Unit(text)` | Подпись единицы. |
| `Slider()`, `Field()`, `Buttons()` | Выбор элементов. Если ни один не вызван: **с диапазоном** — ползунок и поле, **без диапазона** — поле и кнопки. |

Значения, заданные из кода, тоже приводятся к правилам: при `Range(0, 120)` присвоение `Speed.Value = 1000` даст `120`.
В поле можно вводить дробную часть и через запятую, и через точку.

### Choice — выбор из списка

```csharp
Units = Menu.Choice("units", "Единицы скорости", "ms")
            .Option("ms",  "м/с")
            .Option("kmh", "км/ч")
            .Option("kn",  "узлы");

if (Units.Value == "kmh") { ... }
```

- `Option(key, label = key)`: `key` — постоянный ключ (его видят код и файл сохранения), `label` — подпись для игрока.
- `.Value` — **ключ** варианта. Неизвестный ключ (например, если вариант убрали в новой версии) заменяется значением по умолчанию.
  Если ключа по умолчанию нет среди вариантов, по умолчанию берётся первый вариант.
- Список показывает до 10 строк, дальше прокручивается. Если внизу не хватает места, он раскрывается вверх.
- `Keys` — все ключи вариантов.

### Text — строка текста

```csharp
ShipName = Menu.Text("name", "Имя корабля", "Странник")
               .MaxLength(32)               // по умолчанию 256
               .Placeholder("Введите имя...");
```

- Текст однострочный: переводы строк заменяются пробелами, лишнее сверх `MaxLength` обрезается.
- Поле работает как ванильное: щелчок ставит курсор, выделение — Shift + стрелки / Home / End,
  протаскиванием мыши или Shift + щелчком, Ctrl+A; Ctrl + стрелки — переход по словам, Ctrl+Backspace / Ctrl+Delete — удалить слово,
  Ctrl+C / Ctrl+X — копировать или вырезать выделенное; зажатые клавиши повторяются.
- **Enter** принимает ввод, окно при этом остаётся открытым.
- **Ctrl+V недоступен**: whitelist модов не позволяет читать буфер обмена.
- Пустое или иное недопустимое значение мод отклоняет в [`Applying`](#applying-проверка-и-отказ).

### Hotkey — горячая клавиша

```csharp
LinkKey  = Menu.Hotkey("link",  "Связать",          MyKeys.R);
MultiKey = Menu.Hotkey("multi", "Выбор нескольких", MyKeys.R, MyKeyboardModifiers.Control)
               .CheckConflicts()   // подсвечивать красным, если сочетание занято
               .EvenInMenus();     // срабатывать и при открытом чате или окне

public override void UpdateAfterSimulation()
{
    if (LinkKey.IsNewPressed())  StartLink();   // нажали в этом кадре
    if (MultiKey.IsPressed())    ...            // держат сейчас
    if (LinkKey.IsNewReleased()) ...            // отпустили в этом кадре
}

string hint = "Нажмите " + LinkKey.DisplayText + ", чтобы связать";   // "Ctrl + R" — названиями клавиш игры
```

**Одна клавиша на действие**, к ней по желанию Ctrl / Shift / Alt. Назначить можно любую клавишу клавиатуры и **любую кнопку мыши**,
включая левую и правую (`MyKeys.LeftButton`, `RightButton`, `MiddleButton`, `ExtraButton1/2`).

**Что видит игрок:** строку как в ванильном «Управлении» — подпись слева, кнопка с клавишей справа.
Щелчок по кнопке открывает надпись «Нажмите клавишу или кнопку мыши»: **Esc** отменяет, **Delete** очищает назначение.
Пока игра ждёт нажатия, курсор скрыт.

**Модификаторы проверяются точно:**
- `R` **не** срабатывает, пока зажат Ctrl: `R` и `Ctrl + R` — разные клавиши.
- Если назначен сам модификатор (например, просто `Ctrl`), он срабатывает и при других зажатых клавишах.
- `IsNewReleased()` модификаторы не проверяет.

**Чат и окна:** пока открыт чат или любое окно с курсором, `IsPressed` / `IsNewPressed` / `IsNewReleased` возвращают `false`,
поэтому клавиша не срабатывает, когда игрок печатает. `.EvenInMenus()` отключает это для отдельной клавиши.

**Конфликты** (`.CheckConflicts()`, **по умолчанию выключено**): клавиша рисуется красным, если то же сочетание занято
в управлении игры, другой клавишей вашего мода или клавишей другого мода центра. Где именно — сказано в подсказке.
Это только предупреждение, сохранить такую клавишу можно. По умолчанию проверка выключена: только ваш мод знает, где работает его клавиша
(в игре R занята лишь с оружием в руках), а моды без центра всё равно не видны.

**Пустая клавиша** (игрок нажал Delete) — это `Value.IsNone == true`; такая клавиша никогда не срабатывает.
Если моду клавиша обязательна, откажите в `Applying`.

`HotkeyValue` (структура):

| Член | Что это |
|---|---|
| `Key`, `Ctrl`, `Shift`, `Alt` | Клавиша и модификаторы. Левый и правый Ctrl, Shift и Alt не различаются. |
| `IsNone` | Клавиша не назначена. `HotkeyValue.None` — пустое значение. |
| `IsModifierKey` | Назначен сам Ctrl, Shift или Alt. |
| `DisplayText` | `"Ctrl + R"` — названиями клавиш игры, для подсказок на HUD мода. |
| `new HotkeyValue(MyKeys, MyKeyboardModifiers)` | Создаёт значение, например для `e.Set` или `.Value =`. |
| `ToString()` / `TryParse` | `"Ctrl+Shift+R"` — формат файла сохранения; `""` — клавиши нет. |

### Label, Separator, Button

Это не настройки, а оформление и действия:

```csharp
Menu.Label("Текст во всю ширину колонки. Переносится по словам и рисуется серым, как ванильные пояснения.");
Menu.Separator();
Menu.Button("Сбросить статистику", () => ResetStats())
    .Tooltip("Удаляет всю собранную статистику");
```

- `Label(text)` и `Separator()` возвращают `Entry`, у которого можно менять `Enabled` / `Visible`.
- `Button(label, action)` срабатывает **сразу**, без «ОК». Чтобы сначала спросить игрока, вызовите
  [`ShowConfirm`](#сообщения-и-вопросы-игроку) внутри действия.

### Общее у всех настроек

```csharp
T     Value { get; set; }    // текущее значение; присвоение из кода не вызывает Changed и ничего не сохраняет
T     Default { get; }       // значение для кнопки «По умолчанию»
event Action<T> Changed;     // значение изменил игрок (после «ОК», от которого мод не отказался)
.Tooltip("текст")            // всплывающая подсказка, как у ванили
bool  Enabled, Visible       // у любого элемента: настройки, кнопки, текста, разделителя, группы
string Key, Label            // то, что передали при создании
```

- `Enabled = false` — элемент серый и не нажимается. У группы это действует на всё её содержимое.
- `Visible = false` — элемент скрыт, и место, которое он занимал, исчезает.
- Менять `Enabled` / `Visible` можно когда угодно, окно подхватит изменения само. Обычно это делают в `Menu.Editing`.
- Если присвоить `.Value` при открытом окне, новое значение появится только в строках, которые игрок ещё не трогал.

## События: от открытия окна до «ОК»

Центр не пытается угадать логику мода: он сообщает о каждом шаге, а мод сам решает, что делать.

```
Opened ─► Editing (Changed = null) ─► Editing ... Editing ─► «ОК» ─► Applying ─┬─ отказ ─► сообщение об ошибке, окно открыто
                                                                               └─ принято ─► .Value обновлены ─► Changed ─► Applied ─► Closed(true)
                                                   «Отмена» / Esc / × ─► Closed(false)
```

| Событие | Когда |
|---|---|
| `Opened` | Окно открыто. Сразу за ним приходит `Editing` с `Changed == null`. |
| `Editing(SettingsEdit e)` | Игрок что-то изменил в окне, **ещё до «ОК»**. |
| `Applying(SettingsApply e)` | Нажата **«ОК»**. Новые значения ещё не применены, и от них можно отказаться. |
| `.Changed(value)` у настройки | Для каждой изменённой настройки, после того как обновилось её `.Value`. |
| `Applied` | Один раз, после применения всех значений. Здесь удобно сохранять. |
| `Closed(bool ok)` | Окно закрыто: `true` — через «ОК» (после `Applied`), `false` — «Отмена», Esc или крестик. |

До «ОК» значения живут в **черновике окна**. `.Value` меняется только после того, как «ОК» принят.

### Editing: изменения на лету, Enabled, Visible, пресеты

```csharp
Menu.Editing += e =>
{
    // e.Changed — какая настройка изменилась (null — окно только открылось или нажато «По умолчанию»)
    // e.New(настройка) — значение в окне, ещё не применённое
    HudGroup.Enabled = e.New(ShowHints);           // группа серая, пока галочка снята
    Code.Visible     = e.New(Units) != "ms";       // строка видна только при некоторых вариантах

    if (e.Changed == Preset)                       // пресет заполняет другие значения
    {
        if (e.New(Preset) == "fast") { e.Set(Accel, 2f); e.Set(Speed, 90f); }
    }
    else if (e.Changed == Accel || e.Changed == Speed)
        e.Set(Preset, "custom");                   // поправили руками → «Свой»
};
```

- **Когда вызывается:** галочка, список и клавиша — сразу; ползунок — непрерывно, пока его тянут;
  текстовое и числовое поле — когда ввод принят (Enter или щелчок мимо поля).
- `e.New(s)` — значение в окне; `e.IsChanged(s)` — отличается ли оно от текущего `.Value`.
- `e.Set(s, value)` меняет другое значение в окне так, как будто его поменял игрок. Чтобы оно применилось, всё равно нужен «ОК».
  Значение приводится к правилам настройки (диапазон, шаг, варианты, длина).
- После «По умолчанию» `Editing` вызывается с `Changed == null`, поэтому тот же код правильно выставит Enabled / Visible.

### Applying: проверка и отказ

```csharp
Menu.Applying += e =>
{
    if (e.New(ShowHints) && e.New(HudScale) > 1.5f)
        e.Cancel("Подсказки при масштабе больше 1.5 не помещаются на экран", HudScale);

    if (e.New(ShipName).Trim().Length == 0)
        e.Cancel("Имя корабля не может быть пустым", ShipName);

    if (e.New(LinkKey).IsNone)
        e.Cancel("Назначьте клавишу для «Связать»", LinkKey);
};
```

- `e.Cancel(message, focus = null)` — центр показывает сообщение в ванильном окне **«Ошибка»** поверх настроек.
  Окно настроек **остаётся открытым**, и всё, что ввёл игрок, сохраняется. `focus` подсвечивает подпись этой настройки красным.
- `e.New(s)` / `e.IsChanged(s)` работают так же, как в `Editing`. `e.IsCancelled` показывает, отказал ли уже другой обработчик.
- Простые границы проверять не нужно: `Number` сам держит `Range` / `Step`, `Text` — `MaxLength`,
  `Choice` принимает только свои варианты.
- Текст ошибки пишите на языке игрока: язык игры моду тоже доступен.
- Если `Applying` бросит исключение, центр покажет «Мод не ответил: ошибка при применении настроек», а исключение попадёт в лог игры.

## Сообщения и вопросы игроку

```csharp
Menu.ShowMessage("Статистика сброшена.");                         // окно с «ОК»
Menu.ShowMessage("Готово.", "My Mod");                            // с заголовком

Menu.Button("Сбросить всё", () =>
    Menu.ShowConfirm("Сбросить все настройки и статистику?", yes =>
    {
        if (yes) ResetAll();
```

- Оба окна показываются поверх игры или поверх окна настроек.

## Сохранение значений

**Центр ничего не хранит.** Мод сам задаёт `.Value` при загрузке и сохраняет значения, когда считает нужным.
Проще всего воспользоваться встроенным помощником:

```csharp
// после описания всех настроек, до Register()
Menu.LoadFromLocalStorage();
Menu.Applied += () => Menu.SaveToLocalStorage();
```

- Файл: `ModSettings_<id>.txt` в локальном хранилище **вашего мода** (`%AppData%\SpaceEngineers\Storage\<ваш мод>\`).
- Формат — строки `ключ=значение`, `#` — комментарий:
  ```
  # My Mod 1.0: настройки (Mod Settings), строки ключ=значение
  speed=20
  hints=true
  units=kmh
  link=Ctrl+R
  ```
- При загрузке: если ключа нет в файле, значение остаётся прежним; лишние ключи пропускаются; испорченное значение
  заменяется значением по умолчанию (со строкой в логе). `Changed` не вызывается.
- **Своё хранение** подойдёт не хуже: задайте `.Value` из своего конфига в `LoadData` и сохраняйте в `Applied`
  или в `Changed` отдельных настроек.

## Своё окно

Если стандартного окна мало:

```csharp
// 1. Своё окно вместо стандартного: щелчок по строке мода в меню шестерёнки вызывает ваше действие
Menu = new SettingsMenu("radar", "Radar Plus", "1.2");
Menu.CustomWindow(() => new RadarSettingsScreen().Open());   // ваш MyModScreen
Menu.Register();

// 2. Стандартное окно и кнопка, которая открывает своё окно для сложного
tab.Button("Редактор маршрута...", () => new RouteEditor().Open());
```

Окно мода (`MyModScreen`) открывается поверх окна центра, **Esc** возвращает к настройкам.

## Без центра и порядок загрузки

- **Порядок загрузки не важен.** Если центр загрузился раньше мода, он принимает `Register()` сразу. Если позже — он рассылает
  «я готов», и клиентский файл регистрируется заново сам.
- **Значения работают и без центра.** `.Value`, `IsPressed()`, сохранение и загрузка живут в клиентском файле.
  Если центра нет, у игрока просто нет окна настроек, а `Menu.IsConnected` остаётся `false`.
- Если центр старее клиентского файла (у него старая версия протокола), он не принимает меню. Клиент пишет строку в лог,
  а мод продолжает работать с текущими значениями.

## Правила и ограничения

- **Не меняйте `ModSettings.cs`.** Копируйте его как есть, а для обновления заменяйте новой версией из этого репозитория.
- **Не меняйте `id` и ключи (`key`) настроек** между версиями: от них зависят сохранённые значения и работа центра.
  Подписи менять можно свободно.
- **Ключи должны быть уникальны в пределах меню.** Если ключ повторяется, центр не примет меню и напишет об этом строку в свой лог.
- **C# 6** и whitelist модов: клиентский файл соблюдает оба ограничения. Пишите свой код тоже на C# 6, потому что игра компилирует моды сама.
- **Только личные настройки.** Значения хранятся на компьютере каждого игрока. Серверных настроек (общих, от админа) нет.
- **Ctrl+V** в полях ввода нет: whitelist не даёт читать буфер обмена. Ctrl+C и Ctrl+X работают.
- На свои окна (`MyModScreen`) действует лимит игры на окна модов. Ожидание клавиши центр рисует внутри своего окна, поэтому его оно не расходует.

## Если что-то не работает

Смотрите лог игры: `%AppData%\SpaceEngineers\SpaceEngineers_*.log`.

| Строка лога | Что значит |
|---|---|
| `ModSettings| Mod Settings V…` | Центр загружен. |
| `ModSettings client: <id>: центр принял меню` | Центр принял ваше меню. |
| `ModSettings client: <id>: центр Mod Settings устарел…` | Центр старее вашего клиентского файла. |
| `ModSettings client: <id>: ошибка в …` | Ваш обработчик события бросил исключение (дальше — полный стек). |
| `MOD_ERROR` / `is prohibited` | Игра не скомпилировала мод (whitelist). |

- **В меню Esc нет шестерёнки** — центр не загружен. Проверьте зависимость или добавьте центр в мир.
- **Шестерёнка есть, а вашего мода в списке нет** — не вызван `Register()` или в меню повторяются ключи.
- **Клавиша не срабатывает** — открыт чат или окно (см. `EvenInMenus`), не совпадают модификаторы (`R` ≠ `Ctrl + R`)
  или клавиша не назначена (`IsNone`).
